## 响应式断点策略

| 断点 | 宽度 | 布局变化 |
|------|------|----------|
| Mobile S | 320-374px | 单列，紧凑间距 |
| Mobile M | 375-767px | 单列，标准间距 |
| Tablet | 768-1023px | 双列卡片，热点区域更大 |
| Desktop S | 1024-1439px | 侧边栏+内容，对比左右排布 |
| Desktop L | 1440px+ | 更大图片，更多留白 |

### 关键响应式变化点

| 页面 | Mobile (< 768px) | Desktop (≥ 1024px) |
|------|-------------------|---------------------|
| 首页 | 单列卡片 | 双列卡片 |
| 房型总览 | 底部抽屉 + 全屏滚动 | 右侧固定面板 |
| A/B对比 | 上下堆叠 | 左右分栏 |
| 搜索 | 全宽输入 | 居中窄输入 |
| 管理后台 | 汉堡菜单 + 底部导航 | 固定侧边栏 |
| 检查清单 | 单列 | 双列 |
